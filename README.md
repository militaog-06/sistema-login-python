# 🔐 Sistema de Login em Python

Projeto desenvolvido durante meus estudos de Python, com o objetivo de praticar estruturas de repetição, condicionais e controle de tentativas.

## 📚 Conceitos praticados

- Variáveis
- input()
- Conversão de tipos com int()
- Estruturas condicionais (if/else)
- Operadores de comparação
- Operador lógico 'and'
- Contador com '+='
- Controle de fluxo

## ⚙️ Funcionalidades

- Solicitação de usuário e senha
- Validação da senha
- Limite de 3 tentativas
- Mensagem de acesso permitido
- Bloqueio após exceder o número de tentativas

## 🚀 Como executar

É necessário ter o Python instalado.

No terminal, execute:

```bash
python main.py
