
# 🔐 Sistema de Login em Python

Meu primeiro projeto prático desenvolvido durante meus estudos de Python, com foco em lógica de programação e estruturas de repetição.

## 📚 Conceitos praticados

- Variáveis
- Entrada de dados com input()
- Estruturas condicionais (if e else)
- Estrutura de repetição while
- Operadores de comparação
- Operador lógico 'and'
- Contadores
- Controle de fluxo com break

## ⚙️ Funcionalidades

- Validação de usuário e senha
- Limite de três tentativas
- Exibição de tentativas restantes
- Mensagem de acesso permitido
- Bloqueio após exceder as tentativas

## 🛠️ Tecnologias

- Python 
- Git
- GitHub
- Visual Studio Code

## 🚀 Como executar

1. Instale o Python.
2. Clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

bash
python main.py
